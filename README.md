# Pedro Henrique Santos Garcia — Portfólio

Estudante de Ciência da Computação na PUCPR, em Curitiba. Um portfólio para conectar aprendizado, design e tecnologia por meio de projetos reais.

## Projetos

- **O Tirano:** jogo narrativo 2D inspirado em Édipo Rei, desenvolvido no Construct 3. Concepção, pesquisa e desenvolvimento de Pedro; mapas em pixel art de Maria; apoio do ChatGPT na programação em blocos.
- **Pedro Hand:** fonte funcional criada a partir da minha caligrafia.
- **Quiz de Lógica Proposicional:** em desenvolvimento com duas amigas. A versão final ainda não foi publicada.
- **Robótica / TechBot:** três registros de projetos de 2021 — carro que desvia de obstáculos, separador de bolinhas e cofre eletrônico.

## Abrir localmente

Baixe o repositório e abra `index.html` no navegador. Para usar um servidor local, execute `python3 -m http.server 4173` na pasta e acesse `http://localhost:4173`.

O site usa HTML, CSS e JavaScript, sem instalação de dependências. A fonte Pedro Hand e as imagens estão incluídas. Para preparar uma pasta de publicação, execute `python3 build.py`.

## Estrutura

- `index.html`: início, trajetória e contato.
- `projetos/`: apresentação de cada projeto e coleção de robótica.
- `certificados.html`: documentos reais de formação e participação.
- `style.css` e `script.js`: estilos, contatos e interações.
- `assets/`: fotos, fontes e certificados.
